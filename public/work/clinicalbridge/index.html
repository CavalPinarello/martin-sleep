Clinical software

ClinicalBridge

Moved a psychiatry practice's medical records to a new system. Paid, and in production.

Code on GitHub

What I built

A practice was changing its electronic health record system, and every chart had to arrive intact. I wrote the toolkit that did it: export, check, map every field, load, then verify that what arrived matches what left.

It keeps an audit log, encrypts what it touches, has a dry run and a rollback, and comes with a visual field mapper so a non-programmer can see what goes where.

How it works

  1. 01ExportStructured data through the old system's API, documents as PDFs.
  2. 02Check and mapValidation first, then every field mapped to its new home.
  3. 03Load and verifyRecords go in, and each one is compared against the original.

What's next

Nothing. It did its job, and the practice runs on the new system.
